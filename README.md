# دستیار صادق (نسخهٔ ۰.۱)

۱. پوشهٔ پروژه را در Android Studio باز کن (File > Open)
۲. صبر کن Gradle Sync تمام شود
۳. گوشی را با USB وصل کن (USB debugging روشن) و Run بزن
۴. دکمهٔ 🎤 را بزن، مجوزها را بده و بگو: «به علی زنگ بزن»

نکته: در تنظیمات گوشی، زبان فارسی برای Google Voice Typing / تشخیص گفتار نصب و فعال باشد.

## بدون اندروید استودیو
پروژه را در یک مخزن GitHub آپلود کن؛ فایل .github/workflows/build.yml خودکار APK می‌سازد.
از تب Actions > آخرین اجرا > Artifacts فایل APK را دانلود کن.
